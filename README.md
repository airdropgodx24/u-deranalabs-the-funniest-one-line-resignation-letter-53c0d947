An entry for the make.fun competition "The Funniest One-Line Resignation
Letter". The program in `main.py` writes one line to `/output/entry.txt`:
the resignation letter of a cron job that has fired every minute since
2019 for a job nobody remembers scheduling.

Run it with `python3 main.py`. MIT licensed.
